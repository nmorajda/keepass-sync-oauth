Privacy Policy

Last updated: October 17, 2026

Overview

KeePass Sync OAuth is a private integration for synchronizing an encrypted KeePass password database with Google Drive using rclone.

Data Access

The integration uses the Google Drive API with the drive.file OAuth scope. Access is limited to files created or explicitly authorized for use by the application.

Data Storage

The KeePass database is encrypted before being uploaded to Google Drive. OAuth credentials and access tokens are stored locally in the rclone configuration.

Data Sharing

This integration does not intentionally share personal information with third parties. Files stored on Google Drive are subject to Google's applicable privacy policies.

Data Retention

Data remains under the control of the Google account owner and may be deleted from Google Drive at any time.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
