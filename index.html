KeePass Sync OAuth

KeePass Sync OAuth is a personal, non-commercial integration used to synchronize an encrypted KeePass password database with Google Drive through rclone.

Purpose

The integration allows its owner to store and retrieve an encrypted KeePass database using Google Drive.

Google Drive Access

The integration uses the Google Drive API with the drive.file OAuth scope to access files created or authorized for use by the application.

Privacy

No personal information is collected by this website. The KeePass database remains encrypted.
